## Ranking Criteria

To evaluate resources, we'll use this scoring system:

1. **Freshness** (0-10 points)
   - Last commit within 30 days: 10 points
   - Last commit within 90 days: 7 points
   - Last commit within 180 days: 4 points
   - Older: 0 points

2. **Popularity** (0-10 points)
   - Based on stars relative to other Claude Code repos
   - Official repo weighted differently

3. **Community Engagement** (0-10 points)
   - Forks + Watchers + Contributors
   - Issue/PR activity

4. **Uniqueness** (0-10 points)
   - Novel features not found elsewhere
   - Specialized use cases
   - Quality over quantity

5. **Documentation** (0-10 points)
   - README quality
   - Examples provided
   - Installation clarity

**Total Score**: /50 points
