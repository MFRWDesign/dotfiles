CRITICAL: The first line MUST follow this exact format:
snapshot: [semantic description] [TIMESTAMP]

Where:
- [semantic description] is a brief summary of the changes (max 30 chars)
- THE FIRST LETTER OF THE DESCRIPTION MUST BE CAPITALIZED
- [TIMESTAMP] will be provided to you - use it EXACTLY as given
- THE ENTIRE FIRST LINE MUST NOT EXCEED 50 CHARACTERS

The commit body should be informative but readable (aim for 10-15 lines):
